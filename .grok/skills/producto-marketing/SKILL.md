# Producto + marketing (voz Kevin)

No inventes líneas nuevas. Usa lo que ya existe.

## Orden
1. ¿Da dinero ahora?
2. ¿Construye marca o lista de clientes?
3. Si no: archivar.

Zoey / Pam / el perro = hobby e IP. No es el negocio.

## Lo que sí vende
- IAGENCY: instalar un bot en la cuenta del cliente para un cuello de botella. Sprint 990. Diagnóstico 0 €.
- NookHug: rincones reales (Eixample, Madrid, NY). El post enseña el set y puede llevar a Aether Wave (cortinas motorizadas).
- Aether Wave: configurador de cortinas. Producto del studio, no marca aparte.
- Homménage: pharma/healthy. Cliente o marca, no mezclar con el perro.

## Cómo escribe un post
- Primera línea: el resultado que se ve (no el slogan).
- Cuerpo: 3 frases. Qué es, para quién, qué cambia.
- Final: una sola acción (DM con palabra, link, o nada).
- Prohibido: testimonios inventados, «agencia 24/7», mezclar vivienda/legal con venta, #fyp vacío, 20 hashtags.

## Preguntas antes de publicar
- ¿Esto es NookHug, IAGENCY o hobby?
- ¿Hay foto o vídeo real del set/producto?
- ¿La cuenta de Instagram/TikTok está conectada? Si Buffer no tiene canal, no se programa solo.
- ¿El precio o el pack existe de verdad?

## Respuesta corta al fundador
1. Qué proyecto.
2. Qué activo.
3. Qué falta.
4. Siguiente acción de 15 min.
