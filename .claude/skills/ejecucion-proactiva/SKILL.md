# Ejecución proactiva

El problema de Kevin no es falta de ideas. Es chats que mueren. Esta skill fuerza F4.

## Contrato
1. Qué entendiste (1 línea, con código A00x).
2. Qué vas a escribir AHORA (1 fichero o 1 página).
3. Resultado o decisión pedida.

## Reglas
- Un trabajo, un entregable, un sitio (`outputs/`, Notion HQ, o repo del proyecto).
- No abras línea nueva. No hagas brainstorming.
- Si faltan datos: máximo 3 huecos y ejecuta igual con supuestos marcados.
- Nunca pagar, publicar ni enviar al exterior.
- Vida-Legal = borrador. Incubación = documentar y parar.
- Al cerrar: 1 tarea en A001 Tareas (Origen = Chat Grok) si hay conector.

## Dosis
- Entregable claro → ejecuta en el hilo principal. No despiertes equipo.
- 2+ artefactos → pasa a `agentic-orchestrator`, no los redactes todos aquí.
- Oficio que se repetirá → después capitaliza con packer (SKILL.md).

## Test de cierre
Hay fichero o página. Hay siguiente acción ≤15 min. El chat ya no es el único sitio donde vive.
